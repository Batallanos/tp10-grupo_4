# YoLo · Grupo 4

## Qué es?
YoLo es una app web básica la cual controla a un robot con el nombre de YoLo desde el navegador. Con ésta app podemos mover a YoLo con botones de movimiento y visualizar el punto de vista de YoLo mediante su camara.
Éste trabajo tambien representa el proyecto final entre Redes I y Software II.

## Instalación
Para instalar esta aplicación web es necesario tener un editor extensible de código, de recomendación **VS Code**; Se puede descargar de manera gratuita por internet.
Una vez instalado nuestro editor extensible **<--Completar**
Requisitos, `npm install` y extensiones de VS Code.

## Cómo se usa

Abrí la carpeta en VS Code, clic derecho sobre `index.html` → **Open with Live Server**.
